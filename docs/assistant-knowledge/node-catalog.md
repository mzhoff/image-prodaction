# Каталог нод для Ask AI и QA

## Generate Image: модели OpenRouter

Generate Image показывает живой список растровых моделей OpenRouter с логотипами:
включая GPT Image 2.5 Flare/Sunburst, MAI, Muse, Seedream, Qwen Image, Krea,
Recraft, Flux, Grok, Gemini и Riverflow, пока они присутствуют в каталоге.
Нужен существующий OpenRouter credential Workspace.

`model`, `aspectRatio`, `size` и дополнительные `imageQuality`, `imageBackground`,
`imageFormat`, `imageCompression`, `imageSeed` сохраняются в графе и pinned runtime
config. Доступные значения берутся из OpenRouter `/images/models` и
`/images/models/{modelId}/endpoints`; `node_catalog.imageGenerationModels` сообщает
тот же контракт агенту. Нет универсального 1K/2K/4K: `size=auto` оставляет размер
провайдеру и не передаёт resolution. Flare/Sunburst предлагают качество и фон;
необъявленные размеры и форматы не выдаются за поддержанные.

Один запуск — одна PNG/JPEG/WebP-картинка. SVG-only варианты исключены.
До четырёх референсов с более строгими минимумом/максимумом модели; некоторые
модели требуют референс, некоторые работают только с текстом. JPEG не поддерживает
прозрачность. Сжатие задаётся только для JPEG/WebP, если объявлено моделью.
Перед постановкой в очередь и перед отправкой сервер проверяет сочетание настроек.

Старые model ID продолжают работать через Chat Completions. Новые используют
OpenRouter Images API в той же очереди, с сохранением результата и usage.
Потерянный ответ после отправки не приводит к автоматическому повтору оплаты.
Refine и отдельный редактор маски сохраняют прежний каталог; новые image-модели
не означают поддержку масок. Недоступная модель не заменяется автоматически.

## Generate Video (`generateVideo`)

Готовые локальные результаты Crop/Export принимаются на first/last frame и
reference-1..3 без ручного сохранения. По нажатию Generate полные обработанные
файлы сохраняются в текущем Workspace, затем их серверные ID фиксируются в запросе.
Thumbnail и исходник до обработки не подставляются. Неподготовленный/утраченный
файл блокирует запуск; повтор существующего job использует те же сохранённые ID.

Result содержит плейсхолдер в выбранном aspect ratio ещё до генерации. Во время
работы — одно визуальное ожидание внутри него, без отдельного большого блока.
Generate всегда остаётся на карточке; обработка и понятные красные ошибки находятся
под кнопкой без HTTP-кодов. Проверка и отмена текущего job доступны компактно.
Стрелки версий находятся поверх плеера слева, а Library, download и fullscreen —
справа. Видео можно воспроизвести прямо в карточке или полноэкранном просмотре.

Один фрагмент по prompt, first/last frame или до 3 reference images. `prompt:text`
доступен всегда, `video:video` — выход. Режим `text` скрывает image-входы,
`frames` открывает `first-frame` и поддерживаемый `last-frame`, `references` —
`reference-1..3`; смешивать режимы нельзя. Название модели показывается без
provider/gateway, рядом с локальным знаком семейства. Параметры — из живого
каталога, без догадок о поддержке. До 30 секунд / 128 MiB; inline JPEG
до 2048 px, оригиналы сохранены. Фоновая очередь, безопасная проверка прежнего
job, приватный результат, Library и история версий. Оплаченная операция может
продолжиться после отмены. Runtime handler `ai.video.generate@1` поддерживает
публикацию; строгий бюджет fail-closed при неизвестной оценке стоимости.
Ask AI объясняет сценарии text/frames/references, точный settings-контракт и
пример `textPrompt -> generateVideo -> pipelineOutput`, но не запускает генерацию.
При создании из провода картинки автоматически выбираются режим `frames` и
совместимая модель живого каталога. Для Timeline Frames (в том числе через Router)
выбираются `references` и `reference-1`, чтобы сохранить всю галерею одним проводом.
Если каталог или подходящая модель недоступны, показывается ошибка до создания ноды.
Подробности и первичные источники: [video-generation](../video-generation.md).

Seedance может отклонить кадр, распознанный как реальный человек, включая
сгенерированный портрет. Это отдельная причина отказа, а не ошибка баланса
или формата. Для такого кадра можно выбрать другую модель; запрос не повторяется
автоматически. Код и очищенное объяснение поставщика сохраняются в истории job.
Отдельно возможен отказ сгенерированного звука из-за авторских прав: видео тогда
не выдаётся. Вариант без звука или другую модель пользователь выбирает явно.

Текстовые фрагменты: [жесты, поля и ограничения](../text-fragments.md).
Это обычная Prompt (`presentation=card`); legacy bubble открывается карточкой.
Бейджи над полями переносят текст с непрозрачным превью карточки; Alt — копия.
Drop в Prompt/Extract/Text Gen/Generate image/Refine, suffix Text concat и поля
паспортов добавляет текст и объединяет одинаковые `[секции]`. Formatter принимает
новые абзацы без потери оформления, из него копируется свободный текст.
Один Undo отменяет перенос целиком. Полностью опустевшая Prompt удаляется со
связями только после переноса всего текста в другую ноду; частичный перенос,
Alt-копия и drop на канвас сохраняют источник.
Платного запуска нет. Read-only/locked/running источники копируются;
связанные `@Alias` не отделяются от входов.

Источник истины — типизированный реестр
`src/entities/production-graph/model/node-help.ts`. Он обязан содержать metadata
для каждого `ProductionNodeType`; серверный `node_catalog` добавляет к ней
статические порты реестра, правила динамических портов и разрешённые assistant settings. Этот документ — короткий тестовый индекс,
а не второй независимый реестр.

## Вопрос Ask AI

Для выбранной ноды чат открывается с черновиком, но не отправляет его:

> Расскажи, что такое нода «{label}» (тип {type}) в Image Production, для чего
> она нужна и когда её использовать. Объясни её входы, выходы и ключевые
> настройки, перечисли возможности и ограничения, затем приведи короткий пример
> связки с другими нодами. Используй актуальный node_catalog. Ничего не изменяй
> в текущем документе — нужен только ответ.

Черновик использует только канонические `label` и `type`: данные, настройки и ID
конкретной карточки в него не попадают.

## Превью, оригиналы и перемещение

На канвасе ImagePlate, маленькие референсы, Sketch, Crop и Adjustment preview
показывают отдельные WebP-миниатюры до 560 px. Оригинал остаётся в закрытом S3;
image-порты, генерация, вычисление Crop/Adjustment, скачивание и полноэкранный
просмотр не используют миниатюру как исходник. Полноэкранные редакторы также
сохраняют полноразмерный источник. HTTP-кэш оригиналов приватный, без отдельной
неограниченной копии всех оригиналов в памяти приложения.

Перетаскивание ноды — временное визуальное движение карточки и прилегающих линий.
После отпускания мыши фиксируются координаты; Escape отменяет движение. Выделение
поднимает карточку через CSS z-index, не меняя порядок нод и связи.
Автоматический обзор проекта формируется при выходе кнопкой Back в отдельном
Web Worker; ручной Make snapshot остаётся точным снимком и имеет приоритет.
Закрытие всей вкладки не гарантирует завершение фоновой загрузки.

## Добавление соседних нод в Studio

`Add to output` / `Add to input` доступны для одиночного и группового выделения.
Меню берёт доступные ноды из общей палитры и пересекает совместимость с каждой
выбранной нодой по её текущим портам (включая реальный image/audio/video у Import).
Для каждой выбранной создаётся своя новая нода: три Import → три Crop, а не один
Crop с тремя входами. На вход используются свободные порты либо порты, явно
разрешающие несколько связей; лимиты референсов сохраняются, существующие связи
не заменяются. Создание, соединения и расстановка пар — одна отмена/повтор.
Настраиваемое поле новой Pipeline input/output получает тип соседнего порта.
Пустое пересечение оставляет пункт неактивным: справа в одной строке шеврон, затем
знак вопроса с объяснением. У доступного пункта знак вопроса не показывается.
`Send to Extract` — отдельное действие: одна общая Extract, максимум 5 изображений.

## Extract: Preset и Layers

`analysisPreset` выбирает `composition` (совместимый default), `graphics`,
`character` или `location`. `presets` — массив выбранных Layers, `preset` —
прежнее одиночное поле; `default` означает все слои выбранного профиля.
Точные ID и подписи каждого слоя доступны в живом `node_catalog`.

Стандартный промпт собирается из задач выбранных слоёв. Смена профиля сохраняет
его prompt и Layers в черновике; возвращение восстанавливает их. Явная смена
Layers пересобирает prompt.
Анализ запускается отдельно кнопкой Analyze и оплачивается как раньше.
В Studio изображения сравниваются вместе; server runtime сейчас анализирует
только первое изображение. Публикация фиксирует профиль, слои и prompt.
Сохранённые старые ноды продолжают использовать Composition.

Состав профилей, правила текста и совместимость: [Extract presets](../extract-analysis-presets.md).

## Критические правила связок

- Сборка агентом по брифу должна заполнять исходный `textPrompt.settings.text`,
  правила `textGeneration.settings.instruction` и запрошенные настройки, например
  `generateImage.settings.aspectRatio = "16:9"`. Пустой Result до запуска — норма;
  потерянные известные инструкции — ошибка. Бриф длиннее 4000 символов делится
  между Text prompt и собирается через Text concat, а не обрезается.
- В Agent/MCP ошибочное `textGeneration.settings.prompt` восстанавливается как
  `instruction` с предупреждением. Разные `prompt` и `instruction` в одном запросе
  или невалидный текст отклоняются для исправления, а не заменяются defaults.
  Это совместимость аргументов tools, не новое поле ноды или runtime.
- `@brief` в Generate Image не подставляет текст ноды с таким ключом. Текст приходит
  по связи; именованные переменные объявляются в Text prompt через `variables`.
- QR, CTA и другие необязательные элементы добавляются только по задаче, не по
  наличию ноды в каталоге. Если QR не запрошен и не требуется сохранить из референса
  или графа, агент не добавляет его и не спрашивает, нужен ли он. Правило отдельного
  сканируемого QR-слоя применяется только к действительно нужному QR.

- При drop файлов на канвас карточка над нижней панелью сразу показывает этап
  подготовки, конвертации HEIC в JPEG или загрузки и счётчик обработанных файлов.
  Прогресс считается по файлам, а не по байтам или предполагаемому времени.
  После первых обработанных файлов показывается отдельная оценка оставшегося
  времени по измеренной скорости; она может меняться с размером файлов.
  Ошибка отдельного файла не прерывает пачку: успешные файлы добавляются одной
  отменяемой операцией, итог показывает успехи/ошибки. Успешный итог исчезает через
  5 секунд, ошибки остаются до закрытия. Это обратная связь Studio, без новых
  портов, настроек MCP или изменений executable runtime.
- Timeline Handoff: `importImage.original -> timelineHandoff.video`, затем
  `timelineHandoff.timeline -> pipelineOutput.field:<id>` с `kind: json`.
  Сначала FFmpeg-разбор, затем ручная проверка, затем отдельное Describe current/all.
  До 5 минут / 100 планов / 5 кадров на план / 1500 Unicode-символов описания.
  Перелистывание, изменение границ и выбор кадра не вызывают модель автоматически.
  Frames, Descriptions и Fragments передают выбранный фрагмент или всю серию;
  выбранный видеоклип подготавливается без AI. JSON всегда содержит полный разбор.
  Нет сцен, подробных пресетов и прямого video-to-text AI.
  Исполняемый pipeline переносит только проверенный immutable snapshot; новый
  исходник сначала разбирается в Studio. Полный контракт: [Timeline Handoff](../timeline-handoff.md).

- Для executable text-поля, которое нужно вставить в постоянную инструкцию:
  `pipelineInput.field:<id> -> textPrompt.variable-N -> textPrompt.text`.
  В шаблоне используется `@fieldKey`. Canvas показывает имя source даже когда
  runtime value ещё не известен; значение подставляется при запуске.
- Прямая связь `pipelineInput.field:<id>` с обычным text-входом означает, что
  внешнее значение является всем входом, без постоянного текста вокруг него.
- Для изображения, которое нужно конвертировать до публичного результата:
  `producer.image -> exportImage.image-0 -> exportImage.image ->
  pipelineOutput.field:<id>`. Выход Export — преобразованный первый image, а не
  исходник; batch не имеет отдельного collection-порта на canvas.
- Аудиорежим Import сохраняет технический тип `importImage` и ID выхода `image`,
  но фактический `kind` — `audio`. Не подменяйте тип данными из названия порта.
  Пустая Import не получает аудиосвязь до загрузки записи; `mediaKind` не является
  настраиваемым агентом параметром. Перенос вложений `sourceAttachmentIndex`
  пока работает только для изображений.
- Распознавание: `importImage.image -> speechToText.audio`, затем
  `speechToText.text -> textGeneration.text`. Только текст, без обещаний
  диаризации, тайм-кодов слов или готовых субтитров.
- Озвучка и подготовка файла: `textGeneration.result -> textToSpeech.text`,
  `textToSpeech.audio -> audioConvert.source`, `audioConvert.audio ->
  pipelineOutput.field:<id>` с `kind: audio`. Export image не конвертирует аудио.
- Видео в Import имеет три отдельных выхода: original/video — kind video,
  audio — выбранная звуковая дорожка. Параметр videoAudioTrackIndex берётся из
  метаданных, не выдумывается. В Studio производные файлы подготавливаются кнопками.
  Максимальная потоковая загрузка видео — 1 ГиБ, длительность до 30 минут; анализ
  Timeline Handoff по-прежнему ограничен пятью минутами исходника.
  Studio/Library ждут фоновую проверку после сохранения оригинала в S3: pending
  не выдаётся за готовый файл. Закрытая вкладка не останавливает уже принятое
  задание проверки; незаконченный перенос файла при этом прерывается.
- Telegram Publication принимает до 10 файлов, суммарно до 100 МиБ. Multipart
  читается потоком; исходники отправляются из временных файлов. Это обычная явная
  публикация по кнопке, не фоновый автоматический вызов и не новая возможность MCP.
- Voice принимает до 30 000 символов / 30 минут. Свыше 5000 символов сервер
  автоматически делит текст и собирает один MP3. Продолжать прежнюю задачу безопаснее,
  чем создавать новую: каждая физическая часть оплачивается отдельно. Отмена не
  гарантирует остановку уже отправленного провайдеру вызова.
- Voice показывает символ мужского/женского голоса только по подтверждённым данным.
  Нейтральная иконка — пол не подтверждён. Play рядом с селектором проигрывает
  готовую пробу конкретной модели и голоса, не создаёт generation job, не меняет
  выход ноды и историю. Пока записи нет, кнопка недоступна с подсказкой.
  [Тексты и план записи 35 текущих вариантов](../voice-auditions.md).
- В explicit pipeline image/audio Import сохраняется как managed
  `asset.reference`; video Import — `video.import`, готовящий подключённые выходы.
  В старом неявном режиме только image/audio остаётся внешней входной границей.
  Аудиофайл приватен, принадлежит Workspace и скачивается по защищённому пути.

Форматы, лимиты и последовательность локальной проверки:
[Аудиопайплайны](../audio-pipelines.md).

## QA каждой ноды

У Generate Image общий `reference` и тематический `style` — разные входы.
Перезагрузка, восстановление и перенос проекта сохраняют выбранный вход каждой
связи. Сворачивание Reference меняет только отображение. Изображение не становится
референсом стиля автоматически. Подключите три изображения в `reference`, текст
в `style`, сохраните и переоткройте документ: распределение должно остаться прежним.

1. Открыть контекстное меню карточки и нажать Ask AI.
2. Проверить, что чат открылся, а вопрос появился только в composer.
3. Проверить канонические `label` и `type` и отсутствие ID/данных карточки.
4. Отправить вопрос и сверить назначение, порты, settings, возможности,
   ограничения и короткий пример с ответом актуального `node_catalog`.
5. Для `referenceComposer` учитывать `hidden-incomplete`; её нельзя создать из
   Add menu. Для `banner` Ask AI объясняет, что нода не участвует в dataflow.

## Личный выбор моделей

В Generate Image, Refine, Reference Composer, Subject Builder, Text Gen, Extract, Generate Video, Text to Speech и Speech to Text используется общий селектор. All сортирует совместимые модели по названию A–Z; Most popular показывает их по числу успешных заданий пользователя за всё время во всех рабочих пространствах. Одно задание считается один раз независимо от ретраев; неуспешные задания, локальная обработка и задания сервисных клиентов не учитываются. При равной популярности порядок A–Z. Без истории список пуст.

Favorite хранит порядок добавления; повторное добавление после удаления помещает модель в конец. Звёздочка доступна при наведении, фокусе с клавиатуры и на сенсорном экране во всех вкладках. Она не выбирает модель и не закрывает меню. Поиск сохраняет порядок выбранной вкладки. Последняя вкладка (по умолчанию All) и избранное сохраняются на сервере в аккаунте отдельно для text/image/video/audio, общие для разных нод того же типа. Настройки → Аккаунт → Избранные модели позволяет добавлять, удалять и переставлять модели стрелками. Недоступные модели остаются в настройках для удаления или сортировки, но не появляются среди совместимых моделей ноды. Auto Router исключён.

Предпочтения не являются настройками графа, не экспортируются, не меняют явно сохранённый model и не дают прав запускать генерацию. Ask AI/MCP объясняет эту механику, но не управляет аккаунтным избранным. Исполнение, порты и ограничения провайдеров остаются прежними.

### Выбор пропорций в генераторах

Generate Image и Generate Video используют общую дискретную шкалу Aspect Ratio. Недоступные форматы скрыты без сдвига остальных. Клик подтверждает и закрывает; перетаскивание сохраняет формат при отпускании и оставляет меню открытым. Preview высотой 35 px меняет ширину за 200 ms. Размеры в пикселях показываются только по подтверждённым таблицам; неизвестный размер обозначен «Размер по модели». Crop и Composition сохраняют прежние контролы. Источники и точность: [output-resolution.md](../model-capabilities/output-resolution.md).


## Generate Image: порядок и автоматические секции Prompt

В Studio порядок — **Prompt → Reference → Settings → Generate → Result**.
Изображение, история и выход `image` находятся под Generate. По умолчанию Prompt
содержит пустое поле без списка слоёв. Подключение текста с заголовками `[Actors]`,
`[Style]` или `[любой свой тег]` на отдельных строках создаёт текстовые входы
`prompt-section:<URL-encoded нормализованное имя>` и связи от того же источника.
Входы обновляются после изменения результата/фильтров источника, не запускают AI.
Повторные заголовки объединяются в один вход без потери повторных блоков.

После разбора исходная связь с `prompt` удаляется: вход свободен, локальное поле
остаётся дополнительной инструкцией. Каждый секционный вход передаёт свой блок
один раз в Studio и опубликованном runtime. Текст вне размеченных секций этого
источника не передаётся. Без тегов сохраняется обычная связь с Prompt.
Ручной источник в секции заменяет автоматические источники этого тега;
удалённая автосвязь не возвращается при редактировании, сохранении или загрузке.
Источник секций хранится как метаданные редактора, не как скрытый runtime-вход.
Копирование и импорт переназначают его только на скопированные ноды.

Старые соединения не меняют назначение: подключённые текстовые semantic-входы
показываются в Prompt, image/subject/location — в Reference. Пустые старые входы
скрыты. Общий reference не становится style. Медиа-бейджи в Generate Image,
Generate Video и общих reference-контролах показывают **название ноды-источника**
на голубой заливке по ширине текста; длинное имя доступно целиком в tooltip.
Крестик при наведении отключает конкретную связь; Undo восстанавливает её.


## Ножницы на канвасе

Инструмент **Cut connections** в нижней панели включает рисование оранжевой линии.
Пересечённые SVG-связи заметно темнеют до отпускания указателя. Отпускание удаляет
весь пересечённый набор одной операцией, включая обновление входов и зависимых
результатов. Ctrl+Z/⌘Z возвращает весь набор; Redo повторяет удаление.
Escape или потеря фокуса отменяет незавершённый жест. Инструмент учитывает масштаб
и смещение канваса. Повторный клик по ножницам или V возвращает выбор.
