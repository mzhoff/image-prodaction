# Практический каталог нод

## Текст и инструкции

- Text prompt хранит исходную инструкцию и может принимать динамические текстовые переменные.
- Text concat объединяет несколько текстовых входов с выбранным разделителем.
- Text generation вызывает текстовую модель и превращает входной текст в новый результат.
- Formatter готовит форматированный текст, в том числе для публикационных сценариев.
- Text splitter разделяет текст на коллекцию элементов.
- Text to speech превращает текст в аудио.

## Изображения и генерация

- Import image добавляет исходное изображение в граф.
- Extract анализирует изображение и возвращает текстовое описание.
- Generate image создаёт изображение по prompt и опциональным референсам.
- QR Code детерминированно кодирует URL или текст в настоящий PNG QR-код. Вход
  `text` принимает изменяемое значение, выход `image` подключается к
  `Composition`. Штатный V1: `outputFormat=png`, 1024x1024, correction level `M`, margin 4,
  `#000000` на `#FFFFFF`. Функциональный QR нельзя рисовать через Generate
  image: визуально похожий AI-узор не гарантирует сканирование. Если URL уже
  указан пользователем, его сохраняют в локальном `content`. Если URL не указан,
  ассистент не задаёт дополнительный вопрос и не выдумывает бизнес-ссылку:
  создаёт пустую QR-ноду и сообщает, что её локальное значение нужно заполнить.
- Reference composer собирает текстовый prompt из структурированных референсов.
- Composition объединяет несколько слоёв в одно изображение.
- Sketch создаёт рисованный источник для дальнейшей обработки.

## Обработка изображения

- Crop меняет кадрирование.
- Adjustments регулирует экспозицию, контраст, насыщенность, температуру и светотень.
- Curves выполняет тоновую и цветовую коррекцию кривыми.
- Frequency retouch помогает сгладить тон, сохраняя текстуру.
- Refine / Enhance улучшает или очищает изображение с помощью модели.
- Remove BG удаляет фон.

## Контекст и управление потоком

- Router передаёт данные через именованный вход и выход.
- Iterator последовательно выдаёт элементы коллекции изображений или текста.
- Subject builder формирует устойчивое описание персонажа или объекта.
- Location builder формирует устойчивое описание места и атмосферы.

## Проверка, экспорт и публикация

- Preview показывает изображение без отдельного экспорта.
- Export image выгружает одно или несколько изображений в выбранном формате.
- Telegram publication собирает текст и медиа для публикационного артефакта.
- Banner служит визуальной подписью или разделителем на холсте и не передаёт данные.

## Рецепт: редактируемый рекламный макет

Это обычный авторский граф на canvas, а не опубликованный executable pipeline.
Если пользователь просит просто собрать повторяемый макет, не добавляйте
`Pipeline Input`, `Pipeline Output`, внешний endpoint или runtime-контракт без
отдельного явного запроса.

По умолчанию базовый граф собирается самым коротким рабочим способом:

1. `Generate image.image` служит источником единого основного арта для
   `CompositionBlueprint`:
   героя, фон, встроенный текст, плашки, кнопки, рамки, иконки и декор. Точное
   написание, стиль, предполагаемый шрифт и положение текста описываются в prompt.
2. Если пользователь явно выбрал объект как отдельно редактируемый, для него
   создаётся отдельный источник: `Text prompt`/`Text generation` для текста или
   `Import image`/`Generate image` для изображения. Источник, роль, рамка и
   z-порядок описываются в верхнеуровневом `compositionBlueprints`; внутренний
   порт `layer-N` compiler назначает сам.
3. Пока нет надёжного инструмента извлечения героя из фона, герой и фон по
   умолчанию генерируются совместно. Разделять их следует только по явному
   запросу и через доступный рабочий способ.
4. `qrCode.image` всегда указывается в `compositionBlueprints` как отдельный
   image-слой с ролью `qr`. Указанный пользователем URL подставляется сразу; при
   отсутствии URL оставляется пустое локально редактируемое значение без
   дополнительного вопроса и без выдуманной ссылки.
5. Финальный результат передаётся связью
   `composition.image -> exportImage.image-0`.

Выбранный пользователем набор независимых слоёв фактически задаёт контракт редактируемого макета.
В будущем его можно оформить как переиспользуемый межпродуктовый рецепт и
открывать в другом редакторе, но публикация этого контракта и интеграция с
другими продуктами — отдельный этап, не часть текущей сборки canvas-графа.

Если пользователь ещё не назвал, что хочет менять отдельно, ассистент вызывает
интерактивный `design_element_selection`. Выбор вариантов не изменяет canvas;
после него ассистент готовит один preview `pipeline_build`/`pipeline_update`, и
только этот preview получает штатное подтверждение изменения.

## Совместимость портов

Соединение обычно разрешено только между выходом и входом одного типа: text к
text, image к image и так далее. Порт `any` принимает разные типы. Reference-порты
имеют дополнительные правила для subject, location, image, text и preset.
Если требуется точное имя node type, port id или направление порта, ассистент
обязан вызвать `node_catalog`, а не угадывать по этому описанию.
