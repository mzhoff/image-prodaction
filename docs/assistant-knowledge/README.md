# База знаний ассистента

Эта папка — контролируемый владельцем продукта источник знаний встроенного
ассистента Image Production. Ассистент читает только перечисленные ниже файлы и
серверный каталог нод из кода приложения.

- `product-overview.md` — назначение продукта и основные пользовательские сценарии;
- `executable-pipelines.md` — продуктовая идея исполняемых пайплайнов, текущий
  Runtime API и граница будущего SDK;
- `node-catalog.md` — QA-индекс 30 типов, шаблон Ask AI и короткие тестовые описания;
- `editable-advertising-layouts.md` — предметный язык, стратегия декомпозиции
  референса и правила сборки редактируемых рекламных макетов;
- `assistant-policy.md` — границы ответов и правила безопасности.

Чтобы изменить поведение ответов, отредактируйте Markdown, проверьте факты с
командой продукта и выпустите изменение обычным Pull Request. Секреты, ключи,
персональные данные и внутренние provider payloads сюда добавлять нельзя.

Таблица в `node-catalog.md` намеренно дублирует type, label и классификацию только
как проверяемый QA-индекс. Runtime-источник истины — `NODE_HELP_METADATA` и
`NODE_DEFINITIONS`: tool `node_catalog` читает их из кода и добавляет правила
динамических портов, поэтому модель не должна угадывать контракт по Markdown.
