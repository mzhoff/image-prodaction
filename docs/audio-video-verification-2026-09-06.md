# Long Voice + Import video — локальная проверка

Дата: 2026-09-06. Ветка: `codex/audio-pipelines`.
Изменения выполнены в существующем checkout с сохранением предыдущих правок Transcribe.
Нет изменения Content Hub, подписок, клонирования голоса, миграции БД, Git-публикации
или production deployment. [Отложенные идеи](audio-video-backlog.md).

## Реализованный результат

- Voice: до 30 000 символов, автоматическое серверное разбиение длинного текста,
  последовательная озвучка с отдельным checkpoint и учётом каждого платного вызова,
  сборка одного MP3, прогресс, восстановление и отмена дальнейших частей.
- Общее ограничение результата — 30 минут; обработка — 45 минут от первого старта.
  Неоднозначный ответ провайдера не повторяется автоматически. Короткая озвучка
  до 5000 символов сохраняет прежний формат/контракт.
- Import: MP4/MOV/WebM, сохранённый оригинал, отдельное видео без звука,
  выбранная аудиодорожка, совместимое браузерное preview при необходимости.
  Переключение дорожки не выдаёт старые audio/preview за новый результат.
- Runtime: video.import подготавливает подключённые выходы; scalar video в
  Input/Output, проверка Workspace и защищённое скачивание артефактов.
- Ask AI, MCP/tool schemas, каталог нод, документация и проверки обновлены вместе.

Тяжёлая обработка остаётся на сервере, без нового микросервиса или внешнего конвертера.
Input video не подключается к Import: последняя остаётся узлом загрузки, без входа.
Отдельный service-token upload endpoint для видео не добавлен — внешний Runtime
пока принимает ссылку на уже существующий видеоasset своего Workspace.

## Проверки

- Общий unit-набор: 709 тестов, 701 pass, 8 skip, 0 fail. Проверки настоящих
  кодеков отдельно обязательны: на Mac FFmpeg не установлен.
- Изолированный контейнер с FFmpeg, синтетические файлы: 10/10 pass без skip.
  Проверены MP3/FLAC/Opus, сборка Voice, отмена, MP4/AAC, MOV preview, WebM,
  несколько дорожек и отсутствие тихого усечения многоканального audio.
- `typecheck`, `lint`, `check:architecture`, `check:size`, `git diff --check` — pass.
- Docker build — успешен. Одна сборка используется web, generation worker и pipeline worker.
- Браузер: стиль Transcribe; Import video с выбором дорожки; Voice 202 → polling →
  reload → готовый результат без повторного POST. В последнем тесте генерация и
  media HTTP замоканы: он доказывает UI lifecycle, не качество провайдера.
- Аудио M2M на настоящем локальном HTTP: upload → pinned deterministic conversion
  → download; idempotent replay, MIME/SHA-256, чужой Workspace, недостающие права,
  защищённые артефакты и нулевая стоимость без AI — pass.
- Видео HTTP + M2M: настоящий MP4 upload, извлечение AAC и видео без звука,
  повторная подготовка с теми же asset IDs, неизменный SHA исходника, отказ без
  авторизации/из чужого Workspace, неверный файл и несуществующая дорожка — pass.
  Опубликованный отдельный QA pipeline Import → Output вернул original/video/audio
  через service credential; повторный запуск вернул прежний run. MIME/SHA защищённых
  файлов проверены, usage COMPLETE, providerCallCount = 0. Всего 4 E2E-сценария прошли.

Во время браузерной проверки исправлено смешение portable export/import и обычного
сохранения документа: текущий документ сохраняет ID активной задачи, копия/шаблон — нет.
Также проверены поздняя готовность Workspace и повторный mount effects в StrictMode.

## Локальный контур

Обновлены только `image-prodaction-web-1`, `image-prodaction-worker-1` и
`image-prodaction-pipeline-worker-1`. Все healthy. Прямой localhost:3004 и
существующий proxy 127.0.0.1:7310 возвращают readiness 200.
PostgreSQL, MinIO, Mailpit, volumes и соседние продукты не пересоздавались.
Отдельный dev-сервер на 3007 остановлен после проверки.

После сборки удалён только восстанавливаемый build cache (2.95 GB) и использованный
локальный dev cache (~803 MiB). Docker images не удалялись. Свободное место после
очистки — около 23 GiB, при финальной проверке — около 21 GiB; запас всё ещё
ниже проектного порога 15%. На этой машине параллельно работают другие проекты.
Небольшие отдельные QA-аккаунты/документы/артефакты оставлены для воспроизводимости;
временные ключи API тестов отзываются, пользовательские проекты не менялись.

## Что не следует считать доказанным

- Платная длинная озвучка реальной моделью, её произношение, одинаковая интонация
  частей и качество стыков пока не проверены. Следующий ручной тест — один текст
  10–20 тысяч символов, закрытие/открытие документа и прослушивание итогового MP3.
- Сборка выдала предупреждение Next о слишком широком file tracing из
  video-processor. Артефакт собран успешно, но это отдельная задача оптимизации упаковки.
- `npm audit` исходного lock-файла сообщает 1 high (`fast-uri@3.1.5` через
  ChatModule → ajv) и 4 moderate (цепочка drizzle-kit/esbuild).
  Зависимости в этой задаче не обновлялись. Перед публичным деплоем нужен отдельный
  контролируемый dependency/security check, без автоматического `audit fix --force`.
