# Favorite node presets

## Назначение

`Favorite` сохраняет персональную переиспользуемую конфигурацию одной ноды.
Пресет принадлежит Image Production и не создаёт отдельную модель Identity:
владельцем является текущий аутентифицированный пользователь, а областью —
существующий `workspaceId`.

## Контракт v1

В payload сохраняются только:

- тип ноды;
- изменяемые параметры, prompt и instruction;
- модель и настройки;
- сохранённый результат, когда он является частью полезного пресета;
- ссылки на durable assets, доступ к которым сервер подтвердил для пользователя
  в выбранном Workspace.

Не сохраняются:

- node ID, координаты, размер, lock/status и связи графа;
- in-flight requests, job/idempotency fingerprints и сообщения об ошибках;
- credentials, API keys, tokens, passwords и secrets;
- `blob:`/`data:` URLs и другие локальные object URLs;
- ссылки на assets из чужого Workspace или недоступные пользователю.

Нода, созданная из Favorite, всегда получает новый ID, состояние `idle`,
стандартную геометрию и ни одной связи исходного графа.

## Ограничения и эволюция

- payload версионируется (`payloadVersion = 1`);
- размер payload ограничен 96 KiB в сервисе и CHECK constraint базы;
- разрешено до 200 presets на пользователя в одном Workspace;
- один preset может ссылаться максимум на 50 assets;
- одинаковый payload дедуплицируется по SHA-256 внутри пары user + Workspace.

Следующая несовместимая форма payload должна получить новую версию и явный
read/migration path. Нельзя молча переопределять значение старой версии.
