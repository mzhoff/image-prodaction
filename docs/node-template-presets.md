# Node templates

## Назначение

`Templates` — персональная библиотека сохранённых нод. Шаблон можно создать из
настроенной ноды и затем добавить в любой документ того же Workspace как новый
объект. Это отдельная коллекция от `Favorite`: сохранение в одну коллекцию не
изменяет другую.

Владельцем является текущий аутентифицированный пользователь. Сервер всегда
проверяет его membership в выбранном `workspaceId`; переданный браузером
Workspace служит только селектором и не заменяет проверку доступа.

## Контракт payload v1

Template и Favorite используют один безопасный snapshot-контракт. Сохраняются:

- тип и переименованный заголовок ноды;
- настройки модели, prompt, instruction и применимые параметры;
- число динамических входов (`inputCount`, `mediaInputCount`,
  `imageInputCount`, `layerInputCount`) и динамические поля;
- готовые текстовые результаты, включая `sourceText`, и ссылки на готовые
  изображения, если сервер подтвердил доступ к asset в том же Workspace.

Не сохраняются идентификатор, позиция, размер, связи и runtime-состояние ноды,
in-flight requests, ошибки, credentials, secrets, `blob:`/`data:` URL и ссылки
на недоступные либо чужие Workspace assets. Добавленная из шаблона нода всегда
получает новый ID, стандартную геометрию и состояние `idle`.

При вставке шаблона сведения об изображениях загружаются повторно через
аутентифицированный Asset API и добавляются в новый документ вместе с нодой.
Принимаются только готовые изображения того же Workspace. Недоступные,
удалённые и чужие ссылки исключаются с предупреждением; временная ошибка
загрузки не создаёт частично повреждённую ноду. При переходе в другой документ
незавершённая вставка отменяется. Undo/redo охватывает и ноду, и её asset records.

## API и ограничения

- `GET /api/node-templates?workspaceId=...` — список пользователя;
- `POST /api/node-templates` — сохранить безопасный snapshot ноды;
- `DELETE /api/node-templates/:templateId?workspaceId=...` — удалить шаблон;
- payload ограничен 96 KiB, коллекция — 200 шаблонами на пользователя и
  Workspace, один шаблон — 50 asset-ссылками;
- одинаковый snapshot дедуплицируется по SHA-256 внутри пары user + Workspace.

Компактное представление шаблона содержит переименованный заголовок, тип,
количество входов и не более двух строк наиболее полезных настроек. Вместе это
не превышает четырёх строк в списке Templates.
