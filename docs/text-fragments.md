# Текстовые фрагменты в Studio

Фрагмент на канвасе — обычная Prompt (`textPrompt`, `presentation=card`).
Отдельного синего бабла нет. Старые `presentation=bubble` автоматически открываются
обычными карточками; текст, ID и подключения сохраняются. Серверный executor не меняется.

## Жесты

- Бейджи CAMERA, COMPOSITION, BACKGROUND и других `[секций]` расположены **над**
  текстовым полем. Для текста без заголовка есть бейдж TEXT.
- Потянуть бейдж — перенести заголовок и содержимое блока. Во время движения
  под мышью видна обычная непрозрачная карточка Prompt в масштабе канваса.
- Сбросить на канвас — создать обычную Prompt; в другое редактируемое поле
  или на его бейдж — добавить текст. Заголовок ноды перемещает саму ноду.
- Alt / Option в момент сброса — копия. Выделение части текста также можно
  перетаскивать; всё поле не становится draggable и сохраняет обычное редактирование.
- Источник изменяется только при успешном drop. Если весь непустой текст обычной
  Prompt перенесён в поле другой ноды и после пробелов ничего не осталось, пустая
  Prompt удаляется вместе со своими связями. Частичный перенос, Alt-копия и drop
  на свободный канвас сохраняют источник. Один Undo возвращает обе стороны и связи;
  Redo повторяет.
- Escape, отпускание вне допустимой области, смена документа и устаревший
  исходный текст отменяют жест без потери данных. Клик без перемещения сохраняет
  прежнее переключение фильтра, завершённый drag не переключает фильтр случайно.

## Поля и ограничения

Перенос и приём: Prompt.text, Extract.prompt/result, Text Gen.instruction/result,
Generate image.prompt, Refine.instruction, Text concat.suffix, редактируемые
текстовые поля Subject/Location Builder. В Text Gen меняется только активная версия.
Вычисляемые результаты используются как источники копий, а не как редактируемые входы.

В обычных текстовых полях совпадающие **полные** названия `[секций]`
(без учёта регистра и лишних пробелов) объединяются: целевой текст первым,
входящий снизу. Разные заголовки остаются разными. Отключённая секция не включается молча.

Formatter принимает новые абзацы с сохранением имеющихся rich-text блоков,
ссылок и оформления; одинаковые заголовки там не объединяются. Бейджи Formatter
копируют свободный текст, не вырезая форматированный оригинал.

Read-only, locked (включая заблокированную группу) и running источники только
копируются. Заблокированные, вычисляемые или выполняемые поля не принимают drop.
Связанные `@Alias` нельзя отделить от входов — переносите всю Prompt за заголовок.
Квадратные `[секции]` не являются `@переменными`.

Превью меняет только DOM transform через requestAnimationFrame, не граф.
React рендерит его при начале и завершении; одна транзакция графа на drop.
Никакой генерации, вызова модели или сетевой операции во время жеста.

## Проверки

Unit: границы секций/CRLF, одинаковые заголовки, Alt, stale source, locked source/
target, атомарные Undo/Redo, фильтры, legacy-нормализация, связи, @Alias,
поддерживаемые поля и сохранность rich text. Compiler: тот же executor.
Browser: реальный mouse-down/move/up, превью и отсутствие записей до drop,
бейджи над редакторами, выделение, слияние, приём полями, отмена и reload.
