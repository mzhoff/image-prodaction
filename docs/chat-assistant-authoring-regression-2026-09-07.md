# Сборка по брифу: необязательный QR и потерянные инструкции

Инженерный разбор и QA; не источник инструкций для knowledge_search.

## Подтверждённый случай

В локальном чате о листе персонажа 16:9 пользователь не просил QR.
Ассистент всё равно искал qrCode и предложил QR-слой. Общая системная инструкция
содержала рекламный чеклист и фразу «Даже при простом default QR всегда остаётся
отдельным слоем». Правило сканируемости не было достаточно явно ограничено
задачами, где QR нужен. Это обнаруженный источник смещения, а не доказательство
внутренних рассуждений модели.

После отказа от QR tool pipeline_build получил два Text Gen с `settings.prompt`:
2026 и 164 символа. Text Gen принимает `settings.instruction`. Sanitizer отбросил
оба значения с предупреждениями; в графе остались стандартные инструкции.
`generateImage.settings.aspectRatio` отсутствовал, поэтому сохранился default
1:1. В локальный prompt генератора попал буквальный `@brief`, который не является
ссылкой на ноду. В чате было 0 прикреплённых файлов: ref1–ref5 были только текстом.

## Исправление

- QR и другие необязательные элементы — только по задаче; примеры и прежние
  предположения самого агента не расширяют запрос пользователя.
- Полный бриф хранится в подключённом Text prompt, правила обработки — в
  Text Gen `instruction`, а требуемый формат задаётся настройкой Generate Image.
- Готовый image prompt не требует двух одинаковых платных шагов переработки.
- `@Alias` — механизм Text prompt с объявленными переменными, не универсальная
  ссылка по ключу ноды. Отсутствующие reference-файлы нельзя считать подключёнными.
- В build/update известная ошибка Text Gen `prompt` однозначно восстанавливается
  в `instruction` с предупреждением. Конфликт двух разных значений отклоняется.
- Невалидные или слишком длинные поддерживаемые текстовые настройки отклоняются
  для исправления; нельзя молча потерять их и получить стандартный текст.
  Лимит одного поля остаётся 4000 символов; длинный бриф можно разделить и соединить.

Поля и порты Studio/runtime не изменены. Миграция сохранённых документов не
выполняется; сборка/исправление графа не разрешает автоматически запускать модель.

## Проверка

- Регрессионные тесты build/apply/update: сохранение текста, правил, 16:9,
  отсутствие самопроизвольного QR, восстановление поля, отказ при конфликте,
  невалидном типе и превышении лимита.
- Проверены системные инструкции, описания обоих tools и live node_catalog.
- Фактические аргументы из чата повторно обработаны только в памяти: оба текста
  сохранены посимвольно в patch и preview. Документ не изменён; AI не вызывался.
- Полный локальный unit-набор: 769 passed, 10 skipped, 0 failed.
  Typecheck, lint, architecture и diff-check прошли.
- Локальный web пересобран и запущен с integration overlay; image
  `image-prodaction-web:codex-local` / `c3dcf07175af`. В собранном server bundle
  подтверждено наличие новых правил. Readiness на 3004 и через proxy 7310 — 200;
  из Content Hub alias image-production-api доступен, все 5 bindings HEALTHY.
  Чаты и пользовательские графы не перезаписывались, платные вызовы не запускались.
- Удалён только восстановимый build cache (Docker сообщает 2.984 GB).
  Свободное место на host после очистки около 37 GiB; по округлённому df заметного
  прироста от очистки нет. Контейнеров 29 (14 запущены), volumes 38 — как до сборки.

Статические тесты и повтор аргументов не заменяют оценку нового ответа модели.
Ручная проверка: повторить исходный бриф, убедиться, что QR не предлагается,
в preview заполнены тексты и 16:9, а отсутствие файлов референсов названо явно.
Подтверждать платную генерацию для проверки самого графа не требуется.
