# Flows: обучение и общий поиск

Локальный UI-срез по уточнению владельца от 21.09.2026.

## Поверхности и структура

- Контентные окна Home / Flows / Library / Stories и боковое меню без внешней
  обводки. Их отделяют фон, отступ и скругление. Внутренние карточки сохраняют
  свою независимую границу.
- В шапке Flows рядом с «Новый Flow» кнопка академической шапочки раскрывает
  блок обучения. По умолчанию свёрнут; первое открытие показывает туториалы,
  затем можно переключить на шаблоны. Анимация учитывает reduced motion.
- Быстрые фильтры и переключатель сетка/список находятся после блока обучения.
- Карточки обучения повторяют вложенную геометрию Home в контрастной теме.

## Галерея обучения

`workspace-learning-catalog.ts` содержит редакционный каркас карточек с
заголовками, описаниями и иллюстрациями Home. Видео появится при заполнении
`videoUrl`; сейчас окно честно показывает «Видеоурок готовится».

Публичного каталога исполняемых шаблонов ещё нет. Карточка шаблона открывает
информационную галерею «Шаблон готовится», не создаёт пустой Flow под видом
готового шаблона. Наполнение уроков и версия каталога — отдельный этап.

## Один поиск, разные точки входа

- Кнопка в Flows открывает `WorkspaceSearchDialog` с `scope=flows`.
- Кнопка «Поиск» главного меню открывает тот же компонент с `scope=all`.
- Режимы: все файлы, Flows, проекты, медиа, Storyboard, Timeline.
- Figma-основа: [Navigate Popup 725:3983](https://www.figma.com/design/UA1XIcYdD0DUr5gPCSGUQm?node-id=725-3983):
  общая скруглённая оболочка, отдельная область результатов, боковой выбор
  типа файлов, крупные карточки. На узком экране режимы становятся верхней лентой.
- Native dialog удерживает фокус и закрывается по Escape, крестику или фону;
  после закрытия возвращает фокус кнопке запуска. Поле поиска получает фокус
  при открытии. Контент за диалогом недоступен клавиатуре.
- Документы и проекты открываются по существующим маршрутам. Медиа открывают
  превью внутри того же окна; для видео используется настоящий плеер.

## Данные

Поиск читает существующие API и массивы Workspace. Нового индекса и изменения
прав нет: серверные API по-прежнему проверяют доступ, на клиенте результаты
дополнительно фильтруются по активному Workspace. Удалённые Flow и медиа
удалённых документов исключены. Истории и Timeline загружаются только для
нужных режимов; медиа используют серверный поиск, debounce и курсорную пагинацию.
Устаревшие запросы отменяются, ответы чужого Workspace/query не отображаются.

Поиск не меняет файлы и не запускает платные операции. Модель выдачи покрыта
тестами границ Workspace, типов, удаления, запросов, дублей и сортировки.

## Проверка локального среза

- Typecheck, lint, architecture, file-size и diff-check прошли.
- 9 тестов модели поиска и передачи фильтров медиа прошли.
- В браузере проверены: раскрытие обучения, порядок вкладок, расположение
  фильтров, галерея уроков, поиск по имени, пустой результат, общий поиск из
  меню, просмотр реального изображения, Escape и возврат фокуса.
- Поиск проверен на ширине 390 px: модальное окно вмещается, карточки в две
  колонки, выбор режима прокручивается горизонтально.
- Общая проверка `check:reverie-ui` на этом снимке сообщает о старых неизвестных
  токенах в aspect-ratio-selector.css, generate-video-node.css,
  timeline-media.css и voice-selector.css. Новая поверхность поиска в этот
  список не входит; эти несвязанные файлы не исправлялись в данном срезе.

Изменения локальные, выпуск на сервер не выполнялся.
