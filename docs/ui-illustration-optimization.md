## Отображение

Иллюстрации и превью в `img` и Next `Image` используют `draggable={false}`.
Карточки-ссылки с изображениями также отключают нативное перетаскивание ссылки.
Общее правило `img { -webkit-user-drag: none; }` дополняет атрибут для изображений
из UI-пакетов в Chromium/WebKit. Клики, просмотр, скачивание и рабочее перемещение
материалов, клипов и нод через специально настроенные контейнеры сохраняются.

Карточки Home заполняются изображением целиком по ширине (`cover`) при рамке 1.15:1.
Срезается только небольшой запас фона сверху и снизу; предметы остаются целыми.
Это устраняет видимый стык квадратной картинки с белыми полосами по бокам.
На мобильном используется такая же рамка вместо прежней 2:1.

Фактическая ширина картинки на проверенном desktop — 195 CSS px, на мобильном
с компактным меню — 108,5 CSS px. 512 px достаточно для чёткого отображения 2×.
Изображение подсказки вписано в область около 341×228 CSS px; `sizes` передаёт
эту ширину оптимизатору Next.js вместо прежних 520 px. Текущий шаг загружается
при открытии, без предварительной загрузки изображений скрытых шагов.
Миниатюры направления видео показываются в 72 px и имеют запас до 3×.
