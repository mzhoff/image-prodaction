# Выбор и действия в галерее Library

Меню карточки (правый клик или ⋯) содержит копирование защищённой ссылки,
добавление в проект, скачивание оригинала, «Выбрать» и удаление.
«Выбрать» отмечает текущую карточку и показывает чекбоксы у всех загруженных
карточек. Клик по изображению в этом режиме переключает выбор, не открывает
просмотр. «Готово» возвращает обычное поведение. Смена Workspace или фильтров
сбрасывает выбор; «Выбрать все загруженные» не выбирает скрытые страницы.

Правый клик по отмеченной карточке действует на всю выбранную группу;
по неотмеченной — только на неё. Та же группа доступна через «Действия».
Для нескольких файлов копирование ссылки неактивно с объяснением.
Видео можно скачать и удалить, но добавление на канвас через этот механизм
доступно только для изображений.

Скачивание: один файл — исходный формат и имя; группа — ZIP с уникальными
именами. Прогресс подготовки виден пользователю. Ошибка чтения любого
оригинала отменяет подготовку архива, неполный ZIP не выдаётся за полный.

Добавление в проект: до 100 изображений, только в том же Workspace;
сервер повторно проверяет доступ к каждому asset. Создаются независимые
Import с существующими оригиналами и миниатюрами, без копирования файлов.
Вставка начинается после успешной проверки всей группы; одно Undo отменяет
всю группу, стабильные ID предотвращают дубли при повторном открытии ссылки.

Удаление требует отдельного подтверждения с именами и количеством файлов.
Используется существующий DELETE /api/assets/:id: он необратимо удаляет
оригинал и варианты и делает файл недоступным также в канвасах.
При частичном отказе успешно удалённые снимаются с выбора, остальные можно
повторить. Новая политика хранения, корзина и публичные ссылки не добавлены.

Реализация — в продуктовых карточках и действиях. Геометрия и анимация
MediaGallery, права сервера, приватность ссылок и MCP settings не изменены.
