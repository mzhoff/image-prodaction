# Пробы голосов Voice

Подготовлено 12.09.2026. **Записи ещё не сделаны**: это тексты для согласования и
реестр подключения будущих образцов. Платных вызовов при подготовке не было.
35 сочетаний модель/голос из 9 известных приложению моделей (включая совместимость
со старыми сохранёнными нодами Zonos/Voxtral). Это настроенный список возможностей, не весь ассортимент голосов поставщиков. Динамически
обнаруженная новая модель получает нейтральный значок и недоступную пробу до проверки.

## Как записывать через TextSplitter

1. Выбери ниже **одну модель** (до 11 голосов; общий список из 35 превышает лимит Splitter 30).
2. Блок с ID скопируй в Text Prompt. Разделитель TextSplitter — `===VOICE===` (обычный перевод строки в поле ввода не работает).
3. Блок с репликами скопируй в другой Text Prompt. Разделитель — `===VOICE===`.
   Порядок ID и реплик совпадает. Можно использовать только реплики — по одной на Voice.
4. Выход Splitter подключи к `Voice.text`. **Модель и voice выбираются в Settings**:
   имя в тексте/Concat не переключает голос нейронки. У ноды пока нет входа для voice ID
   и нет автоматического перебора персонажей. Повторяй настройку и запуск по одному.
5. Для короткой пробы передавай только реплику, без названий модели, ID и инструкций
   вроде «прочитай текст»: обычный TTS может произнести их вслух. Сначала проверь
   естественную подачу. Для Gemini режиссёрские указания можно отдельно проверить
   в тексте, но поддержка произвольных provider options в этой ноде не добавлена.
6. Прослушай результат: имя, тембр, русский/английский, паузы, отсутствие щелчков,
   музыки и лишних слов. Характеристики ниже — **предложенная подача для проб**,
   не измеренная характеристика записи. Русские варианты MAI требуют проверки
   произношения: региональный ID остаётся прежним.
7. У Kokoro и Orpheus текущие голоса англоязычные: для записи даны английские реплики,
   русский черновик сохранён в JSON для редакторского согласования. Для default-голосов
   также подготовлена английская проба; конкретный персонаж/пол не обещается.

Все поля, включая русские черновики: [voice-auditions.json](./voice-auditions.json).
Экспорт не вызывает AI:

```sh
node --experimental-strip-types --loader ./scripts/node-test-loader.mjs scripts/export-voice-auditions.ts --model x-ai/grok-voice-tts-1.0 --format names
node --experimental-strip-types --loader ./scripts/node-test-loader.mjs scripts/export-voice-auditions.ts --model x-ai/grok-voice-tts-1.0 --format scripts
```

## Как подключить утверждённые записи

Сохранить утверждённые короткие MP3 в `public/voice-previews/<model>/<voice>-<language>-v1.mp3`
и добавить запись в `public/voice-previews/manifest.json`:

```json
{"version":1,"samples":[{"model":"google/gemini-3.1-flash-tts-preview","voice":"Kore","language":"ru","src":"/voice-previews/gemini-3-1/kore-ru-v1.mp3"}]}
```

Это пример формата, не существующая запись. Только после добавления реального файла
и сборки Play станет активным. Manifest сейчас пустой. Не подставлять временные signed
URL, чужие/private assets или демо другого голоса. Утверждённые образцы — публичные
продуктовые материалы, поэтому публикация записи из личной Library требует согласия.
Проверка тестами запрещает отсутствующие файлы, внешние URL и дубли ключей.
Прослушивание загружает только выбранную готовую запись, не вызывает TTS и не меняет граф.
При смене голоса/модели, закрытии ноды или запуске другой пробы прежняя запись останавливается.

  порядок ID и реплик через настоящий TextSplitter.

  отсутствие автозагрузки аудио, один активный плеер, остановка при смене голоса
  или модели, повтор после ошибки. Проверены светлая и тёмная темы.
- `e2e/video-generation-node.spec.ts`: пустой placeholder, компактные действия,
  восстановление запроса после reload, результат и переключение версий.

Браузерные пробы используют локальные синтетические звук/видео, **не записи голосов**.
Платных AI-вызовов в этих проверках нет. Typecheck, lint и architecture check пройдены.

## Источники и достоверность

- [OpenRouter TTS](https://openrouter.ai/docs/guides/overview/multimodal/tts): голос задаётся отдельным параметром и зависит от модели/провайдера.
- [Google: имена и пол](https://docs.cloud.google.com/text-to-speech/docs/gemini-tts),
  [характер голоса](https://ai.google.dev/gemini-api/docs/speech-generation).
- [Microsoft MAI](https://learn.microsoft.com/en-us/azure/ai-services/speech-service/mai-voices): пол и региональные ID. Тексты и режиссёрские характеристики здесь авторские.
- [Kokoro](https://huggingface.co/hexgrad/Kokoro-82M/blob/main/VOICES.md): пол и английские варианты; характеристики проб — авторские.
- [xAI](https://docs.x.ai/developers/model-capabilities/audio/text-to-speech): описания пяти голосов. Прочитанная официальная страница не содержит поля пола: нейтральный символ до подтверждения, не догадка по имени.
- [Canopy Orpheus](https://github.com/canopyai/Orpheus-TTS): имена; пол в прочитанном первичном источнике не указан. Нейтральный символ до проверки.
