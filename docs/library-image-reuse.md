# Из Library на канвас

## Виды медиатеки

- «Галерея» — адаптивные ряды изображений с исходными пропорциями, без обрезки,
  технических названий, подписей проекта, модели и бейджей происхождения.
  Последний неполный ряд не растягивается на всю ширину.
- «По датам» — та же раскладка, сгруппированная по минуте создания. Над каждой
  группой дата и время в часовом поясе браузера. Это временная группировка, не
  утверждение о принадлежности файлов одному запуску генерации. Подгруженные
  элементы той же минуты присоединяются к существующей группе.
- При наведении или фокусе клавиатуры доступны разрешение, вес оригинала и дата/
  время, а также кнопка действий. Вес берётся из `byteSize` в метаданных API,
  не из миниатюры и не через загрузку оригинала. Отсутствующий вес не выдаётся за 0.
  На сенсорном экране кнопка действий доступна без hover.
- Оба вида сохраняют серверный порядок файлов, фильтры, поиск, контекстное меню,
  копирование, отправку в проект и полноэкранный просмотр. Режим хранится в URL
  (`view=dates`), переживает обновление и возврат из просмотра; переключение вида
  не запрашивает список повторно и не меняет контракт серверных фильтров.
- Используются ленивые миниатюры, без предзагрузки страниц каждого файла.
  Ширина измеряется одним наблюдателем на галерею; невидимые ряды откладывают
  отрисовку. При ошибке миниатюры показана заглушка, без автоматической загрузки
  тяжёлого оригинала. Файл по-прежнему можно открыть нажатием.

QA: `library-gallery.test.ts` (пропорции, порядок, группировка, размеры) и
`e2e/library-gallery.spec.ts` (адаптивность, hover/focus, фильтры, пагинация,
сохранение режима и переходы в viewer).

## Лента просмотра

- Под изображением всегда зарезервирована строка метаданных (18px) и панель
  действий (44px на широком экране, 92px на узком), включая файлы без модели или размеров. Загрузка оригинала,
  смена подписи и переключение файла не уменьшают область просмотра. Размеры
  берутся сразу из метаданных коллекции, не из события загрузки изображения.
  Длинная подпись не переносится на вторую строку. Проверка с задержкой оригинала,
  пустой строкой и сменой файла: `e2e/library-viewer-layout.spec.ts`.
- В Library лента миниатюр занимает всю ширину окна, независимо от размера оригинала.
  Сверху оставлена полоса 76px для закрытия, высота ленты — 104px.
- Верхняя полоса и область закрытия имеют единый тёмный фон до края окна.
  Все миниатюры одинакового размера, без увеличения по центру или при наведении.
  Белая контрастная рамка отмечает ближайшее к центру изображение.
- В основном просмотре выбранное изображение крупнее остальных. Соседи плавно
  уменьшаются по мере удаления от центра и приглушаются чёрным оверлеем.
  Расстояния учитывают уменьшенную ширину: между карточками нет пустых больших
  слотов. Размеры подстраиваются под окно; на узком экране соседи видны частично.
  Обе ленты синхронизированы. Перетяните любую влево/вправо и отпустите: движение
  продолжится по инерции и остановится свободно, в том числе между карточками.
  Автоматической доводки к центру и порога в процентах больше нет: любое фактическое
  горизонтальное движение запускает драг. Быстрый жест может пролистать несколько
  картинок; медленный оставляет небольшой сдвиг, без возврата к исходной карточке.
  Масштаб и высота по-прежнему плавно меняются относительно середины окна, даже
  когда ближайшее изображение стоит не по центру.
  Скорость определяется по короткому отрезку движения: небольшая пауза перед
  отпусканием не обнуляет её. Удержание на месте 300мс и дольше снимает инерцию.
  Нажатие на основной просмотр во время движения плавно тормозит обе ленты, без
  центрирования изображения под указателем;
  продолжение драга сразу передаёт управление руке без скачка позиции.
  Повторный свайп мышью в ту же сторону добавляет импульс к оставшейся скорости,
  а не начинает инерцию с нуля. Свайп против движения тормозит её (достаточно сильный
  разворачивает). Скорость ограничена 8 позициями в секунду. Удержание без движения
  снимает накопленный импульс; пауза перед началом нового движения не делает его
  искусственно медленным. Последнее смещение при отпускании тоже учитывается.
  При работе мышью обратное дрожание менее 3 экранных пикселей не сбрасывает
  историю скорости. Порог относится только к подтверждению разворота: начало
  перетаскивания остаётся однопиксельным. Намеренный разворот считается от
  последней крайней точки, поэтому серия маленьких обратных движений тоже
  разворачивает ленту. После удержания на месте 300мс начинается новый импульс.
  Это навигация, не перестановка файлов. Доступны также клик, прокрутка, стрелки,
  Home/End. Escape во время драга отменяет жест, повторный Escape закрывает viewer.
- Клик по верхней миниатюре явно центрирует её и соответствующее большое изображение,
  даже если ближайшее выбранное изображение уже то же самое. Это работает при
  выборе дальше трёх позиций или во время инерции. Запоминается картинка под
  указателем при нажатии, даже если к моменту отпускания она успела сдвинуться.
- При перетягивании и инерции новые оригиналы не загружаются: в DOM только
  превью ограниченного участка с запасом. Оригинал, URL и действия обновляются
  после остановки для ближайшего к середине изображения, без изменения позиции ленты.
  До этого копирование/отправка временно недоступны, чтобы
  пользователь не отправил предыдущий файл. Первый/последний файл тоже
  центрируются; драг останавливается на краю коллекции, кнопки навигации цикличны.
  Основной просмотр и расчёт координат используют одно окно до 9 карточек,
  в том числе на краях списка. Карточка без актуального положения скрыта до
  отрисовки; она не может остаться полноразмерным изображением поверх галереи.
- Стрелки основного просмотра — крупные ghost-кнопки с мягким затемнением под ними.
  Клик переключает изображение, но перетаскивание с области стрелки управляет
  лентой и подавляет последующий клик. Клавиатурная активация кнопок сохранена.
  При Reduce Motion инерция отключается. Колесо/трекпад не получает двойную инерцию.
  Уход в другую вкладку, потеря указателя или смена размера окна во время драга
  завершают жест в текущей позиции, без центрирования или отката к файлу,
  с которого открыли просмотр. Только явный Escape возвращает предыдущее положение
  покоя, которое тоже может находиться между карточками.
- Фоновая подгрузка следующих страниц не меняет позицию и не прерывает инерцию.
  Подтверждение уже выбранного файла в URL не перезапускает более новый жест.
  Основной просмотр и миниатюры имеют общего владельца движения: устаревшее
  событие отмены на одной ленте не прерывает жест на другой. Диагональный свайп
  не отдаётся вертикальной прокрутке заблокированного фона; pinch-to-zoom доступен.
- Стандартная лента и редактор маски в нодах остаются без изменений.

## Действия с изображением

- В просмотре изображения: нижняя панель «Скопировать ссылку» и «Отправить в проект».
- В сетке: те же действия по правому клику и через кнопку многоточия.
- Копирование помещает в системный буфер постоянную ссылку приложения
  `/api/assets/<assetId>/content`, не временный S3 URL и не токен.
  Откройте проект на том же адресе приложения, кликните свободный канвас,
  нажмите Ctrl+V / ⌘V. В текстовом редакторе вставляется обычный текст ссылки.
- «Отправить в проект» показывает активные проекты рабочего пространства изображения,
  открывает выбранный канвас, ждёт загрузки серверной версии / локального восстановления
  и добавляет новую Import. Без фонового перезаписывания чужой доски.
- Выбор проекта — выпадающее меню у кнопки (или у места вызова контекстного меню),
  без центральной модалки и дополнительного затемнения. Поиск сверху, выбор одним
  кликом. У нижней панели открывается вверх; у края экрана сдвигается внутрь окна.
  Escape закрывает только список и возвращает фокус кнопке. Клик снаружи, повторный
  клик по кнопке или уход фокуса закрывает меню; стрелки и Enter работают внутри списка.
- Вставка использует обычную историю Undo/Redo и автосохранение с revision-CAS.
  Повторная обработка одной команды отправки не создаёт дубликат. Отдельное
  повторное копирование/отправка может создать ещё одну Import с тем же asset.
- Сервер заново проверяет доступ к метаданным; клиент проверяет Workspace,
  готовность, наличие в Library и image MIME. При смене проекта во время загрузки
  незавершённая вставка отменяется. Проекты в корзине не принимают вставку.
- Файл остаётся приватным. Доступ требует сессии и членства в Workspace.
  Чужие URL, URL миниатюр/временные ссылки, аудио и видео этим действием не импортируются.
- Import хранит managed assetId. Канвас загружает WebP-миниатюру (старые assets
  получают её лениво), viewer и порты используют оригинал. Второй оригинал не создаётся.
  Удаление исходного проекта не удаляет опубликованный в Library оригинал.
- Это Studio UX, не новый порт, MCP setting или API исполняемых pipelines.
  При недоступном буфере доступна отправка через выбор проекта. При ошибке
  импорта показано сообщение, команда остаётся в URL для повтора перезагрузкой.

QA: viewer и контекстное меню; системный copy/paste; старый буфер нод не
перехватывает изображение; поиск проекта; сохранение и повторное открытие;
Undo/Redo; тот же assetId/thumbnail; чужой Workspace, недоступный файл,
удалённый проект, смена проекта в процессе запроса.

Регрессии движения: `e2e/library-motion-recovery.spec.ts` открывает viewer из
сетки, подгружает следующую страницу посреди жеста, проверяет прерывания и
несколько последовательных свайпов до остановки инерции. `e2e/library-dock.spec.ts`
проверяет однопиксельный драг, свободную остановку, явное центрирование по миниатюре,
инерцию, синхронизацию лент, touch, Escape и Reduce Motion.
Сценарий `acceleration` отдельно измеряет разгон одинаковыми последовательными
свайпами на обеих лентах, встречный жест, удержание и свайп после долгого нажатия.
`e2e/library-mouse-regression.spec.ts` проверяет 20 повторных свайпов мышью с
микровозвратом перед отпусканием, драг/клик на стрелках, отсутствие фантомных
карточек по краям и сохранение wheel-прокрутки без добавленной инерции.
